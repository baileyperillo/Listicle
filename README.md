# WEB103 Project 1 - *Love and Deepspace Listicle Part 1*

Submitted by: Bailey Perillo

About this web app: This web app has a list of the main characters of the popular otome game, Love and Deepspace. Each character card on the home screen has their picture, name, decriptions of their story, and a link to look more. If you click on that, you can get a more description of them, including their job in the game, what they like to do, and their represented colors.
